## الملفات
- `pos_*.csv` — البيانات بشكل جداول `pos_*` الجديدة تماماً (UTF-8).
- `import_to_supabase.sql` — سكربت التحميل (psql). معاملة واحدة: إما ينجح كله أو لا يكتب شيئاً. آمن لإعادة التشغيل.
- `sql-used-for-extraction/` — الاستعلامات التي حوّلت جداول OpenConcerto68 إلى شكل pos_* (للمراجعة فقط).

## خطوات التشغيل
1. **مشروع تجريبي أولاً**: مشروع Supabase فارغ → شغّل السلسلة `supabase/migrations/0001..0056` → أدخل العملاء الحاليين (`sql/pos-customers-import.sql`) → ثم:
   ```
   cd benamor-migration
   psql "<CONNECTION_STRING>" -v DRY_RUN=1 -f import_to_supabase.sql
   ```
   يطبع الأعداد واستعلامات التحقق ثم يتراجع (rollback) بلا كتابة.
2. راجع: الأعداد، «must all be 0»، ومجاميع السنوات/الفروع مقابل النظام القديم.
3. الإنتاج — خارج ساعات العمل، وبعد نسخة احتياطية من Supabase:
   ```
   psql "<CONNECTION_STRING>" -v DRY_RUN=0 -f import_to_supabase.sql
   ```
4. افتح التطبيق فوراً بعد الاستيراد وتحقق من زمن التحميل (loadAll يجلب كل الفواتير).

استخدم connection string الخاص بـ postgres المباشر (Settings → Database) — يتجاوز RLS. لا تضع كلمة المرور في أي ملف.

## ما يفعله السكربت (بحسب مراجعة مطوّر المنظومة)
- المواقع: بحث بالاسم (فرع 11 يونيو / فرع السراج / مخزن جنزور).
- الموردون: يُدمج بالاسم إن وُجد (فهرس lower(trim(name)) الفريد).
- المنتجات: `ON CONFLICT (code) DO NOTHING` — القيم الحالية لا تُمسّ؛ يُملأ `supplier_id` الفارغ فقط.
- العملاء: مطابقة بالرقم (إذا اتفق الهاتف) ثم بالهاتف المطبَّع (بدون الصفر الأول). أرقام مكررة لأشخاص مختلفين تأخذ لاحقة `-<old_id>` (41 عميلاً). 171 عميلاً جديداً فقط.
- المبيعات 10,218 (منها 458 مرتجعات بكميات سالبة) بأرقامها الأصلية، `created_by`/`idempotency_key` = null.
- الدفعات، دفتر العملاء (رصيد مستحق ≈ 46,962 د.ل)، المشتريات + دفتر الموردين، المبدئيات، التحويلات، المصاريف.
- المصاريف التاريخية على حساب مالي **أرشيفي غير نشط** (`أرشيف النظام القديم (Cadence)`) بلا حركات → رصيده 0، ولا حركات مالية تاريخية.
- المخزون: يُضاف فقط للأزواج (موقع، صنف) التي **لا** يملك النظام الجديد صفاً أو حركة لها؛ مع حركة `adjustment` مرجعها `migration`. الصفوف الحالية لا تُلمس.
- لا تعديل على العدّادات (ترقيم S- والـsequence الخاص بالعملاء لا يتعارضان مع الأرقام القديمة).
